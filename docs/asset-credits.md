# Asset and dependency notes

- Room geometry, dog model, pickups, hand model, animation code, and synthesized audio were created for this project; no remote model, texture, or audio pack is required.
- The five original room photographs were used as spatial/color references only and are not shipped as game assets.
- DM Sans and Fraunces are bundled from their `@fontsource` packages. Their upstream licenses and attribution files remain in the installed packages; both use the SIL Open Font License.
- Three.js uses the MIT license; Rapier uses Apache-2.0. Consult the installed package license files for exact terms and notices.
- The game uses system fallback fonts if a local font cannot load. No generated social-sharing image or external analytics service is included.
